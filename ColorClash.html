Color Clash

Overview

Voice meets
the Stroop Effect.

Color Clash is a browser-based game that I designed and developed entirely on my own using p5.js. The gameplay is inspired by the Stroop Effect, challenging players to think quickly by responding to spoken color commands rather than the text displayed on screen.

The game uses voice recognition as its primary input method, creating a unique interactive experience that combines cognitive challenges with hands-free gameplay.

Development

Built solo,
start to finish.

I was responsible for every aspect of the project, including:

  • Programming the gameplay mechanics in p5.js.
  • Designing and illustrating all visual assets.
  • Creating pixel art and sprite animations in Aseprite.
  • Producing cinematic camera movements and scene transitions in Adobe After Effects.
  • Integrating animations to communicate the game's lore and create a more immersive experience.
